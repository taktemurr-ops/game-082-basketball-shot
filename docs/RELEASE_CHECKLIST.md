# Game-082 release checklist

Current work is a prototype and does not yet meet the full A-to-Z mobile game release standard.

## Implemented in source
- Flutter basketball court and basket illustration
- Aim and shot-power controls, wind effects and shot evaluation
- Ten-shot match, accuracy, streak/bonus scoring and replay
- Eight deterministic unit tests
- Flutter CI workflow for analyze, test and Android debug APK

## Required before final release
- Prove a passing CI run and resolve Flutter analysis failures, if any
- Real Android/iOS device testing and release performance verification
- Expanded basketball content, animations, sound effects and skill levels
- Onboarding, saved progress and accessible/localized settings
- Real monetization: production ads with consent and policy compliance
- Real in-app purchases: store SDKs, backend receipt checks and restoration
- Privacy policy, store listing, ratings, screenshots and compliance review
- Signed Android AAB and iOS IPA with protected certificates and QA

No signed publishing build or proven passing CI run is presently documented.
